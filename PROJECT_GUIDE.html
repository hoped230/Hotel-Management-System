2. What Each File Does

FilePurposeType
pom.xml Maven build configuration. Declares JavaFX dependencies (javafx-controls, javafx-fxml) and the javafx-maven-plugin for compiling and running. Build
HotelManagementSystem.java The single Java source file containing all 15 classes: enums, interfaces, abstract classes, concrete classes, generics, file I/O, threading, collections, hotel logic, and the JavaFX application. Java
login.fxml FXML layout for the login screen. Can be opened and edited in Scene Builder. Uses StackPane, VBox, HBox, TextField, PasswordField, Button. FXML
admin.fxml FXML layout for the admin panel. Defines TableView, ComboBox, GridPane form layout. Scene Builder compatible. FXML
guest.fxml FXML layout for the guest panel. Defines available rooms table and booking form. Scene Builder compatible. FXML
billing.fxml FXML layout for the billing dialog. Loaded at runtime via FXMLLoader to display the bill. Uses GridPane and Separator. FXML
styles.css CSS stylesheet applied to all screens. Defines button styles (.primary-btn, .success-btn, .danger-btn), table styling, input focus effects, and color scheme. CSS
Data files created at runtime: When the app runs, it creates hotel_data.dat (serialized room data), hotel_log.txt (activity log), and hotel_records.dat (RandomAccessFile records) in the project root.

5. Five Additional Features

#FeatureImplementation
1 Permanent Storage in Files FileManager class saves/loads all room data to hotel_data.dat using Serialization. Also uses FileWriter for logs, RandomAccessFile for records. Data persists across restarts.
2 Screen Design with Styles styles.css provides themed styling: navy header bars, blue table headers, color-coded buttons, input focus effects, alternating table rows, card-based login sections.
3 Maven pom.xml manages JavaFX dependencies and build. Commands: mvn clean compile and mvn javafx:run.
4 Billing Management Bill class calculates: base amount + service charge (varies by room type) + 12% GST. Deluxe adds Rs.500 extra, Suite gives 10% discount. Bill shown in a dialog.
5 Scene Builder & Components 4 FXML files (login, admin, guest, billing) designed for Scene Builder. billing.fxml is loaded at runtime via FXMLLoader. Uses 10+ JavaFX components.
